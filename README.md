A program that writes a short poem about agency — the power to stop and to stay — to `/output/entry.txt`.

## Run

```sh
python3 main.py
```

It writes the poem to `/output/entry.txt` (UTF-8, under 280 characters). No network, no dependencies beyond the Python standard library.
